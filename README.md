# 나의 할 일 수첩

달력(월간·주간)과 날짜순 리스트로 보는 개인 할 일 관리 앱입니다. 정한 시간이 되면 윈도우 팝업 알림이 뜹니다.

주소: https://rlaghqls103-dotcom.github.io/todo-planner/

## 설치
1. 크롬이나 엣지에서 위 주소를 엽니다.
2. 주소창 오른쪽의 **앱 설치** 아이콘(또는 메뉴 → 앱 → 이 사이트를 앱으로 설치)을 누릅니다.
3. 앱에서 **팝업 알림 켜기**를 누르고 허용합니다.

## 알아둘 점
- 알림은 앱 창이 켜져 있을 때 뜹니다(최소화는 괜찮습니다).
- 할 일은 PC마다 각자의 브라우저에 저장됩니다. 다른 PC와 동기화되지 않습니다.
- 코드가 바뀌면 앱을 다시 열거나 새로 고침(F5)하면 반영됩니다.
